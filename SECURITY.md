# Security

Barid handles bank SMS and a server key, so security reports are welcome.

Please report a vulnerability privately through GitHub's **Report a vulnerability** button on the Security tab, not in a public issue. Include the steps to reproduce and the app version. You will get an answer within a week.

In scope: anything that lets a message, a one-time password or the pairing key leave the phone other than to the paired server, or lets another app or website read them.
